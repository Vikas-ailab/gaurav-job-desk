# Gaurav Job Desk

An installable, mobile-first job-search workspace for Gaurav Rathore.

## Current scope
- Candidate profile and target-role preferences
- Manual job capture with transparent fit scoring and must-have gate
- Job pipeline and application approval checklist
- CV tailoring workspace with editable text export
- Local-only browser storage

## Important limitations
This starter release does not connect to live job boards, verify vacancies automatically, send applications, or run a background 15-minute scheduler. Do not treat sample or manually entered roles as verified vacancies. No application is submitted by this app.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server. It is a static PWA and can be deployed to a static host.

## Privacy
Data is stored in the browser on the device. Clearing browser storage removes it. Do not enter passwords or sensitive identity documents.
